# DevAlias Android MVP — офлайн-перевірка

Цей чекліст виконується на телефоні після встановлення debug APK. Перед
початком увімкніть авіарежим: застосунку не потрібні Wi‑Fi або мобільні дані.

## Основний сценарій

- [ ] Відкрити DevAlias в авіарежимі: на стартовому екрані є напис
  «Працює без інтернету».
- [ ] Відкрити «Мій профіль», змінити псевдонім і аватар, зберегти, закрити
  застосунок та відкрити його знову: дані профілю збережені.
- [ ] Створити гру з двома командами, вибрати час, кількість раундів,
  складність і категорію.
- [ ] У грі перевірити кнопки й свайпи: праворуч — «Вгадано», ліворуч —
  «Пропущено»; рахунок і наступна картка змінюються.
- [ ] Перевірити паузу: таймер не змінюється, доки гру не продовжено.
- [ ] Дочекатися кінця раунду: видно останнє слово та історію вгаданих і
  пропущених слів.
- [ ] Пройти по одному раунду для кожної команди: партія завершується лише
  після обох ходів.
- [ ] На екрані результату перевірити переможця, рахунок і повну історію слів.

## Збереження й зворотний зв’язок

- [ ] Під час незавершеного раунду закрити застосунок через список останніх
  застосунків. Після нового запуску натиснути «Продовжити гру»: команда,
  таймер, рахунок і картка відновлені.
- [ ] Завершити партію, відкрити «Історія ігор»: нова партія містить дату,
  рахунок, переможця й слова.
- [ ] Відкрити «Статистика»: партії, точність і досягнення врахували новий
  результат.
- [ ] Перевірити звуки та вібрацію для вгаданого, пропущеного слова і кінця
  раунду. Якщо телефон у беззвучному режимі або має вимкнену вібрацію, це
  перевіряється в його системних налаштуваннях.
